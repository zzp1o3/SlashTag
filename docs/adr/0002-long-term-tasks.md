# 0002 - 长期待办完成后保持勾选，完成记录独立存储

- 状态：已接受
- 日期：2026-11-03

## 背景

「长期待办」在不同待办工具里有两种完全不同的含义：一次性长期目标（写完一本书），或每日习惯（每天背单词）。两者的完成语义相反：前者完成后应保持打勾，后者第二天应自动回到未完成。

用户的原话是「选择为长期待办后，在完成后不会被删除」，且没有提出每日重置需求。

## 决策

- 长期待办勾选后**永久保持打勾**并留在列表中；想再做一次需要手动取消勾选。
- 每次「取消勾选 → 再勾选」都产生一条新的完成记录，计入统计。
- 普通任务勾选后进入「今日已完成」，次日从便签消失；完成记录保留。
- 完成记录独立于任务存储（`completions` 表），记录完成时间与该次完成时的超时时长。取消勾选只撤销当天那条记录，更早的记录不受影响。

## 备选方案

- **每日零点自动重置**：更适合习惯打卡，但会让「写完一本书」这类任务每天重新出现，与用户描述不符。
- **加一个「每日重置」开关**：两种语义都能覆盖，但第一版多一个设置项和一套状态机，暂不引入。

## 后果

- 长期待办在「今日已完成」折叠区不重复出现，只保留在主列表；每日统计通过完成记录查看。
- 若未来要支持习惯型任务，需要新增「每日重置」属性并调整勾选逻辑，数据模型可以平滑扩展。
